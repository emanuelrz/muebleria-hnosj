# Hermanos Jota — Showroom Digital (Buenos Aires, 2026)

Showroom digital interactivo de mobiliario artesanal y sustentable para la firma **Hermanos Jota**, desarrollado en base al Manual de Marca Oficial 2026.

## Características

- **Diseño & Identidad**: Tipografía *Playfair Display* e *Inter*, paleta oficial de marca (*Siena Tostado*, *Verde Salvia*, *Alabastro Cálido*, *Vara de Oro*, *Rosa Polvoriento*).
- **Catálogo de 11 Piezas de Autor**: Fichas técnicas, medidas, maderas nativas certificadas FSC (*Algarrobo*, *Quebracho*, *Caldén*) y acabados botánicos.
- **Curaduría de Espacios**: Herramienta de proyección y cálculo de presupuesto en tiempo real.
- **Compromiso de Longevidad**: Información detallada sobre el Programa *Herencia Viva* (10 años de garantía estructural, servicio de restauración, taller de cuidados y recompra garantizada).
- **Casa Taller & Cotizador WhatsApp**: Agendador de visitas para la sede en San Cristóbal (Av. San Juan 2847, CABA) e integración directa con WhatsApp (`+54 11 4567-8900`).

## Tecnologías

- React 18
- Vite
- Tailwind CSS
- Lucide React

## Ejecución Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
